# Core Framework Utilities

This directory contains **core framework utilities** used throughout the AgentQMS framework.

## Purpose

These utilities provide fundamental functionality for the framework:
- **Path resolution**: `paths.py` - Centralized path resolution
- **Configuration**: `config.py` - Configuration loading and management
- **Runtime**: `runtime.py` - Runtime environment utilities
- **State management**: `state_manager.py` - State persistence
- **Migration**: `migration.py` - Migration utilities

## Usage

These are low-level utilities used by framework components. For application-level utilities, see `../utilities/`.

## Key Modules

- `paths.py` - Path resolution helpers (framework root, project root, component paths)
- `config.py` - Configuration loader and schema validation
- `runtime.py` - Runtime environment detection and utilities
