# Application Utilities

This directory contains **application-level utilities** for specific use cases and workflows.

## Purpose

These utilities provide higher-level functionality for specific tasks:
- **Logging**: `view_logs.py`, `clean_logs.py` - Log management
- **Context**: `get_context.py` - Context bundle generation
- **Feedback**: `agent_feedback.py` - Agent feedback system
- **Export**: `export_framework.py` - Framework export utilities
- **Browser**: `browser_extension_wrapper.py`, `puppeteer_wrapper.py` - Browser automation
- **Catalog**: `generate_tool_catalog.py` - Tool catalog generation

## Usage

These utilities are typically invoked directly or via agent interface wrappers. For core framework utilities, see `../utils/`.

## Key Modules

- `agent_feedback.py` - Agent feedback and issue reporting
- `get_context.py` - Context bundle generation for tasks
- `view_logs.py` - Log viewing utilities
- `export_framework.py` - Framework export functionality
